# Бюджет двоих

PWA для учёта финансов на двоих. Офлайн, LocalStorage, без бэкенда.

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Загрузка на GitHub без папок

Все исходные файлы проекта находятся в корне архива. Распакуйте архив и загрузите файлы в корень репозитория `finance-duo` через Add file → Upload files.

**Важно:** GitHub Actions требует файл workflow именно в `.github/workflows/`. Поскольку этот архив намеренно не содержит вложенных папок, автоматический workflow деплоя в него не включён. Для автоматического GitHub Pages деплоя потребуется создать `.github/workflows/deploy.yml` отдельно; либо используйте локальную сборку `npm run build` и разместите содержимое `dist` на выбранном статическом хостинге.
